# CodeDiff

A fast, native macOS Git diff viewer built with Rust and Slint. Point it at a repository to review working tree changes, staged changes, commit history and commit ranges, with side-by-side or unified diffs, syntax highlighting, and file or hunk level stage, unstage and discard. It watches the repo, so changes made by editors or coding agents show up automatically.

Target: Apple Silicon, macOS 12 or later.

## Build and run

```sh
cargo run --release
```

Set `CODEDIFF_OPEN=/path/to/repo` to open a repository directly. Set `CODEDIFF_STARTUP_TRACE=1` to print the time to first frame.

## Package

```sh
scripts/make-dmg.sh
```

Produces `dist/CodeDiff.app` (ad-hoc signed, bundle id `com.codediff.app`) and `dist/CodeDiff.dmg` with an `Applications` symlink. The script assembles the `.app` by hand (binary, `Info.plist`, `.icns` via `sips` and `iconutil`) because `cargo-bundle` does not currently build. The `[package.metadata.bundle]` section in `Cargo.toml` is kept for use with `cargo bundle` where it works. `assets/icon.png` is generated by `scripts/gen-icon.py`.

## First launch (Gatekeeper)

The app is not notarized. After dragging it to Applications, the first launch is blocked. Open System Settings > Privacy & Security, find the CodeDiff message and click "Open Anyway", then confirm. Alternatively, right-click the app and choose Open.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| Up / Down | Move selection in the file list (Changes tab) |
| s | Stage the selected file |
| u | Unstage the selected file |
| Cmd+Backspace | Discard the selected file (asks for confirmation) |
| Esc / Return | Dismiss or confirm dialogs |

## Performance

Measured on Apple Silicon with a release build, against a shallow clone of ripgrep (depth 300):

| Metric | Target | Measured |
| --- | --- | --- |
| Cold start to first frame | under 1 s | 93 to 266 ms (first run after build 266 ms, then about 94 ms) |
| Idle memory (RSS, repo open, 5 s idle) | under 100 MB | 93 to 98 MB |
| Refresh after 50 file writes | under 300 ms | 161 to 173 ms from last write to the status update, including the 150 ms debounce |

Idle memory is close to the limit. The refresh figure is measured at the controller level (`cargo run --release --example refresh_bench -- <repo>`), not through the rendered UI.
